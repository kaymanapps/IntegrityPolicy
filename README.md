# IntegrityPolicy
Integrity policy for Single Flash App and Waste To Energy App

Single Flash is a calculation app for a very specific calculation tasks, nothing is saved, no data is gathered or saved anywhere.  There are no logins or anything of that kind.

Waste to Energy App is a calculation app for very specific tasks, the user only inputs numbers, no data is gathered or stored anywhere.  There are no logins or anything of that kind.
